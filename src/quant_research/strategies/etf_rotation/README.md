# ETF 轮动

在固定 ETF 池中按月比较动量、趋势与波动率特征，再通过统一的风险、成本、组合构建和约束模块形成多资产目标权重。

## 目标与适用范围

策略面向流动性较好的场内基金资产配置研究，仅在信号日与下一执行日跨月时调仓，保持多头且不使用杠杆。

## 数据与因子依赖

- 场内基金日线 `fund_daily_bar`
- 场内基金复权因子 `fund_adjustment_factor`
- Alpha 直接由策略运行内的价格窗口计算，不依赖因子注册表

## 信号与调仓逻辑

单因子模式使用指定窗口收益率；复合模式加权多个动量窗口和价格相对趋势，并扣减实现波动率惩罚。数据不足的 ETF 会记录无效原因，剩余有效标的交给五模块流水线构建组合。

## 组合与风控

流水线顺序固定为 Alpha、Risk、Cost、Construction、Constraint。风险模型、成本模型、构建方法、持仓数、单标的上限、换手和敞口约束由 `pipeline` 显式声明。

## 参数

| 参数 | 含义 |
| --- | --- |
| `pipeline.frequency` | 固定为 `MONTHLY` |
| `pipeline.alpha` | ETF 池及单因子或复合 Alpha 参数 |
| `pipeline.risk` | 无风险模型、样本协方差或收缩协方差 |
| `pipeline.cost` | 固定、线性或平方根冲击成本模型 |
| `pipeline.construction` | 等权 Top-N 或均值方差构建 |
| `pipeline.constraints` | Long-only 持仓与换手约束 |

## 执行假设

评分只使用信号日可见的前复权价格，目标在下一交易日转成整数股订单。基础佣金取自唯一 A 股交易规则，不允许由策略参数覆盖。

## 局限与失效场景

固定 ETF 池不能自动处理新品种发现；月频信号可能错过月内快速反转；较短历史、停牌或异常价格会减少有效候选。
