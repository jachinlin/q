# 股票多因子

在信号日可投资股票池内对单因子或多因子截面进行稳健标准化和加权评分，按周通过统一五模块流水线构建受约束的多头组合。

## 目标与适用范围

策略用于 A 股截面选股与组合构建研究，仅在信号日与下一执行日跨周时调仓，不承担独立因子统计研究职责。

## 数据与因子依赖

- 股票日线、停牌、风险警示、日频估值和行业归属数据
- PIT 动态股票池
- `pipeline.alpha` 声明的一个或多个注册因子

## 信号与调仓逻辑

策略对信号日股票池读取因子长表，先按交易日和因子执行 MAD 缩尾与标准化，再按方向或权重汇总。有效因子数不足的证券会记录无效原因；其余评分交给组合流水线。

## 组合与风控

流水线顺序固定为 Alpha、Risk、Cost、Construction、Constraint。组合必须满足 Long-only、持仓数量、单股权重、行业权重、换手、流动性和总敞口约束。

## 参数

| 参数 | 含义 |
| --- | --- |
| `pipeline.frequency` | 固定为 `WEEKLY` |
| `pipeline.alpha` | 单因子方向，或因子权重与最少有效因子数 |
| `pipeline.risk` | 无风险模型、样本协方差或收缩协方差 |
| `pipeline.cost` | 固定、线性或平方根冲击成本模型 |
| `pipeline.construction` | 等权 Top-N 或均值方差构建 |
| `pipeline.constraints` | Long-only 持仓、行业、流动性和换手约束 |

## 执行假设

股票池、因子和证券状态均绑定信号日与目录身份，目标在下一交易日转为整数股订单。基础佣金来自统一交易规则。

## 局限与失效场景

结果依赖所选因子的经济含义与 PIT 可用性；因子共线、行业集中、覆盖率下降或交易成本上升都可能削弱表现。策略研究结果不能替代独立因子研究结论。
