# 双均线趋势

使用单一 ETF 的前复权收盘价比较短期与长期移动平均线，在趋势转强时满仓、趋势转弱时空仓，适合验证简单趋势跟随在明确交易成本下的表现。

## 目标与适用范围

策略用于研究单一场内基金的中期趋势，不进行截面选股、杠杆或做空。决策频率为每日，订单在下一交易日执行。

## 数据与因子依赖

- 场内基金日线 `fund_daily_bar`
- 场内基金复权因子 `fund_adjustment_factor`
- 不依赖预计算因子

## 信号与调仓逻辑

策略读取截至信号日的连续 `long_window` 个前复权收盘价。短均线严格高于长均线时进入 `LONG`，否则进入 `FLAT`；只有状态变化才产生新目标。首次有效状态为 `FLAT` 时不生成无意义卖单。

## 组合与风控

组合只包含 `instrument_id` 指定的证券。`LONG` 使用 `long_weight`，`FLAT` 固定为零权重；目标差额小于 `target_tolerance` 时不重复下单。

## 参数

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| `instrument_id` | 场内基金证券标识 | 必填 |
| `short_window` | 短均线交易日窗口 | `20` |
| `long_window` | 长均线交易日窗口，必须大于短窗口 | `60` |
| `long_weight` | 多头目标权重 | `1.0` |
| `flat_weight` | 空仓目标权重，当前固定为零 | `0.0` |
| `target_tolerance` | 目标权重差额容差 | `0.001` |

## 执行假设

信号仅使用信号日可见数据，目标在下一交易日转为整数股订单；实际成交价格、滑点、成交量限制和佣金由策略研究执行配置与统一交易规则决定。

## 局限与失效场景

震荡行情可能频繁反转并累积成本；窗口缺失、末行不是信号日或价格非法时，该日标记为无效且不推进状态。
